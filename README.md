اللغة واتجاه الموقع — مهم جداً

The entire website must be 100% Arabic.

Use Modern Standard Arabic (العربية الفصحى الحديثة) for all customer-facing content.

The entire interface must use RTL (Right-to-Left) layout.

This includes:

Do NOT create an Arabic website with an LTR layout.

The design must feel naturally designed for Arabic users from the beginning.

Use elegant Arabic typography suitable for a luxury perfume brand.

Recommended typography direction:

Elegant Arabic serif/display font for major headings

Modern clean Arabic sans-serif for descriptions and UI

Excellent readability on both desktop and mobile
